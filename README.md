# Парсер цитат

Собирает цитаты и авторов с сайта quotes.toscrape.com и сохраняет в Excel.

## Стек
- Python
- requests
- BeautifulSoup
- pandas

## Как запустить
1. Установи зависимости:
   pip install requests beautifulsoup4 pandas openpyxl
2. Запусти:
   python parse_quotes.py
3. Результат: quotes.xlsx
